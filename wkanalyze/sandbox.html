Sandbox Effect Classification (Diff Polarity)

Each commit diff is parsed as normalized Seatbelt S-expressions, tracking rule polarity (allow, deny, and conditional tiers like only-in-use-before-launch or denied-in-lockdown-mode) and canceling pure line-movement / closing-parenthesis shifts:

  • Block More (Tighten): Adds deny rules, removes allow rules, or moves primitives into stricter tiers (e.g., pre-launch only or Lockdown Mode).
  • Allow More (Expand): Adds allow rules, unblocks syscalls/Mach services/IOKit properties, or introduces a new process profile.
  • Combination (Allow & Block): Simultaneously expands and restricts rules (e.g., replacing broad wildcard access with narrower rules plus targeted blocks).
  • No Sandbox Impact: Comment-only edits, formatting, macro deduplication, build guard fixes, or telemetry/logging modifier changes (with telemetry / with no-report).

Purpose Categories & Binary Tags

Commit descriptions and diff semantics are synthesized into six purpose categories, a concise one-line summary, and binary-specificity tags (apple-specific / 3p-specific):

  • Security Hardening: Proactively reducing attack surface, blocking unused syscalls/Mach endpoints, Lockdown Mode hardening, and acting on telemetry.
  • Feature & Process Enablement: Enabling new web platform features, OS frameworks, or new sandboxed auxiliary processes (GPU, WebAuthn, PCM, webpushd, Model).
  • Bug Fix & OS Compatibility: Resolving runtime sandbox violations, crashes, hangs, or iOS/visionOS SDK regressions.
  • Telemetry & Violation Logging: Adding/removing with telemetry or silencing noisy violation reports without altering enforcement.
  • Refactoring, Cleanup & Formatting: Sharing macros, removing dead rules/comments, or formatting.
  • Revert: Reverting a previous sandbox commit due to regressions or build breakage.
  • Binary Tags (apple-specific / 3p-specific): Tracks whether a commit touches rules gated on Apple code signing / com.apple.private.* entitlements vs. (require-not (process-attribute is-apple-signed-executable)) for 3rd-party browser engines.
